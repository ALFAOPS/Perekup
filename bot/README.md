# Бот «Перекуп»

Бот работает на Cloudflare Workers. Это бесплатно, сервер держать не нужно: Telegram сам присылает сообщения боту.

Что делает бот:
- на `/start` присылает картинку, описание игры и кнопку «🎮 Играть»;
- на `/play` и `/help` отвечает кнопкой и подсказкой;
- на любое другое сообщение шутит и присылает кнопку;
- ставит кнопку «🎮 Играть» в меню бота.

## Как запустить

1. Зарегистрируйся на [dash.cloudflare.com](https://dash.cloudflare.com).
2. **Workers & Pages** → **Create** → **Create Worker** (шаблон Hello World). Назови, например, `perekup-bot` → **Deploy**.
3. **Edit code** → удали всё → вставь содержимое `worker.js` → **Deploy**.
4. **Settings** → **Variables and Secrets** → добавь два значения типа **Secret**:
   - `BOT_TOKEN` — токен от @BotFather;
   - `WEBHOOK_SECRET` — придумай длинную строку из английских букв и цифр.
5. Открой в браузере `https://<адрес-воркера>/setup?key=<твой WEBHOOK_SECRET>`.
   Должно появиться «Готово! Бот подключён ✅».
6. Напиши боту `/start`.

Если сменишь токен в @BotFather, обнови `BOT_TOKEN` и снова открой ссылку из шага 5.

## Вариант 2: свой сервер (VPS)

Нужен сервер с Ubuntu или Debian. Бот сам забирает сообщения у Telegram, так что домен и HTTPS не нужны.

1. Зайди на сервер по SSH под root.
2. Выполни одну команду:
   ```
   curl -fsSL https://raw.githubusercontent.com/ALFAOPS/Perekup/main/bot/install.sh | bash
   ```
3. Когда попросит, вставь токен бота. Символы при вводе не видны, так и должно быть.

Скрипт поставит Node.js, скачает бота и запустит его как службу: бот сам перезапускается при сбое и после перезагрузки сервера.

- Логи: `journalctl -u perekup-bot -f`
- Перезапуск: `systemctl restart perekup-bot`
- Сменить токен: отредактируй `/opt/perekup-bot/.env`, потом сделай перезапуск
- Обновить бота: снова выполни команду из шага 2

Cloudflare и сервер одновременно не используй: при запуске на сервере бот отключает вебхук Cloudflare.
